Token Radar ranks pre-token protocols by implied launch value, using category peer multiples (median market-cap/TVL of live-token peers), adjusted by seven-day growth, age with no token, and chain diversity. A dark-terminal dashboard of 200 protocols with sortable/filterable rows, a detail drawer with farm plans, and a live-token tab.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
